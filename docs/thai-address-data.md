# Thai address data

Province/district/postcode data: https://github.com/thailand-geography-data/thailand-geography-json
Snapshot: b8b3fb91c7df1129ff5b43cb46f7fcffadd2156b. MIT license retained in thai-address-data-LICENSE.txt.
Districts retain all distinct postal codes from their subdistrict records. Only a unique postcode is autofilled; districts with multiple postal codes offer a choice.
Province order starts with Bangkok and uses approximate distance between the existing map's province center points; it is not driving distance.
Map source: geoBoundaries gbOpen THA ADM1, https://www.geoboundaries.org/, CC BY 4.0 (https://creativecommons.org/licenses/by/4.0/). Existing simplified coordinates are used only to generate ordering.
Data is bundled locally; no visitor address is sent to an external lookup service.
